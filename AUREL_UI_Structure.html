01Project Overview

AUREL is a premium luxury fine jewelry e-commerce single-page application showcasing fine handcrafted jewelry. The UI follows a modern, minimal, high-end aesthetic with cinematic dark backgrounds, gold accents, and immersive 3D product previews.

Tech Stack

React 18.3 Vite 5 Tailwind CSS 3.4 Framer Motion Lucide Icons React Icons PostCSS Autoprefixer

Key Features

  • Single-page luxury e-commerce experience
  • Premium 3D Jewelry Viewer (Lenskart-style 360° rotate)
  • Cart drawer, search overlay, auth modal
  • Product configurator (karat, diamond size, metal color, quantity)
  • Animated sections with Framer Motion transitions
  • Mouse glow effect, custom loading screen
  • Fully responsive (mobile, tablet, desktop)

06Primary User Flow

Landing→Hero animation + Marquee scroll
Browse→Scroll through CategoryGrid & ProductGrid
Click Product→Opens ProductViewModal with JewelryViewer3D
Configure→Choose Karat / Diamond / Metal / Quantity
Add to Cart→Item pushed to CartContext, modal closes
View Cart→CartDrawer slides in from right
Checkout→(future integration)
