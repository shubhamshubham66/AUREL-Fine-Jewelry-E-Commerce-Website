# AUREL - Fine Jewelry E-Commerce

> Jewelry designed to outlive time.

Premium luxury jewelry e-commerce frontend built with **React + Vite + Tailwind CSS + Framer Motion**.

## Features
- Cinematic hero with parallax & 3D text animations
- Real-time product search with filtering
- 3D product viewer with configurator
- Cart system with quantity controls
- Premium animations throughout
- GitHub Pages & Vercel deployment
- Fully responsive design

## Getting Started
```bash
npm install
npm run dev
```

## Tech Stack
React 18 · Vite 5 · Tailwind CSS 3.4 · Framer Motion 11 · Lucide Icons
